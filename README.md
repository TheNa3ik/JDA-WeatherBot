# 🌤️ JDA-WeatherBot

A Discord bot built with **Java** and **JDA**, providing weather data with custom image generation for visual output.

## 📌 Features

- Get weather for any city (real-time and forecast)
- Generates dynamic image cards with temperature, weather conditions, and city name
- Built with Open-Meteo API, TimeAPI.io and JDA (Java Discord API)
- Uses Java AWT for image creation
